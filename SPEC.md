# Shuyi implementation specification

## Product and scope

Shuyi (书衣) is a standalone Python 3.12+ synchronous CLI that restyles existing DRM-free EPUB 2/3 books without translating, rewriting prose, rebuilding navigation, or upgrading the EPUB version. It is independent of the sibling wenyi project. The built-in Chinese reading theme derives from wenyi's chinese-reading.css. Confirmed behavior includes model-based semantic analysis and changing safely identified note reference/backlink labels to the real character `注`. No browser service, GUI, plugin framework, multi-provider routing, rule-only fallback, conversion, DRM removal, or general malformed-book repair.

## Commands and configuration

- `shuyi style INPUT [-o OUTPUT] [--css PATH] [--reanalyze] [--config PATH]`: default output is INPUT's sibling `STEM.shuyi.epub`. Never overwrite input or existing destination, including symlink/hardlink aliases. Missing model configuration is an explicit error, not rule fallback. Cached valid analysis can be used without contacting the model. Write a temporary archive in destination directory, independently verify against the source and change plan, publish without clobbering a racing destination, clean temporary output on every failure.
- `shuyi inspect INPUT`: local, model-free inventory summary, version, documents, candidate/group counts, protected documents, warnings. Must work without credentials.
- `shuyi check INPUT [--epubcheck]`: model-free archive, package, internal-reference and generated-theme-integrity checks. `--epubcheck` invokes the installed executable and propagates errors; missing executable fails explicitly. Standalone checking cannot prove equality to an unavailable original.
- Both installed `shuyi` and `python -m shuyi` use the same CLI.
- Strict TOML, default `~/.config/shuyi/config.toml` (XDG_CONFIG_HOME honored), explicit config errors when missing. `[model] base_url`, `name`, and either `api_key_env` or `api_key` are accepted. Both explicit credential sources together fail validation; empty/non-string literal keys fail. Literal keys are held as SecretStr, excluded from model repr and redacted in serialization. Local plaintext credential files must be kept outside version control and should have mode 0600. base_url must be http(s), nonempty model, api_key_env is an environment variable name. Default endpoint https://api.openai.com/v1; OPENAI_API_KEY is the default key variable when no literal is supplied; OPENAI_MODEL and OPENAI_BASE_URL can supply defaults when no configured value is supplied. Custom CSS paths resolve relative to invocation directory; config has no CSS field. Never print secrets or source excerpts in errors.
- Console messages/logs and documentation are English. Code comments/docstrings are Simplified Chinese. Chat with the user is Simplified Chinese.

## Dependency and ownership boundaries

Use uv, hatchling, zipfile, lxml, tinycss2, cssselect2, Typer, Rich, Pydantic, OpenAI SDK. No EbookLib read/rebuild roundtrip. `contracts.py` is neutral, produced and owned by the main agent; never modify its public API without escalation.

- `epub/`: safe ZIP I/O, namespace-aware markup primitives, OPF/manifest/spine model, local link validation, structural protections. May import contracts; no layout/theme/application imports.
- `layout/`: candidate inventory, original CSS evidence, strict model protocol, deterministic sampling/checkpoints. May import contracts and epub public APIs; no theme/application imports.
- `theme/`: CSS validation, cascade-safe plans, note recognition and rendering. May import contracts and epub public APIs; no layout/application imports. Receives Inventory and LayoutProfile data.
- `verify/`: independently validate planned changes and preservation; may import contracts and epub public APIs, not theme/layout implementation. It must not simply call the writer to regenerate expected output.
- `application.py`: production composition root and orchestration. Constructs analyzer, injects dependencies, loads config and coordinates publish. CLI calls application, not private subsystem internals.
- `cli.py`, `config.py`: main-agent ownership. All errors exposed as ShuyiError with stable sanitized codes. Unexpected failures must not leak book text or credentials through CLI tracebacks.

## Shared contracts

Exact Python dataclasses and Protocol live in `src/shuyi/contracts.py`. Paths are archive-relative POSIX paths. ElementPath is the tuple of element-child indices from document root, ignoring comments/PIs. Source fingerprint is SHA256 of exact input EPUB bytes. Node identifiers are deterministic `n000001` etc in manifest/spine and DOM order, not model-assigned.

Public subsystem API:

```
epub.archive.load_book(path: Path) -> Book
epub.archive.write_book(book: Book, replacements: dict[str, bytes], destination: Path) -> None
epub.dom.parse_xml(data: bytes, resource: str) -> etree._Element
epub.dom.serialize_xml(root: etree._Element) -> bytes
epub.dom.element_path(root, node) -> ElementPath
epub.dom.resolve_element(root, path: ElementPath) -> etree._Element
epub.package.resolve_href(resource: str, href: str) -> tuple[str, str] | None
epub.package.check_references(book: Book) -> list[str]
layout.inventory.build_inventory(book: Book) -> Inventory
layout.analysis.analyze(inventory: Inventory, classifier: Classifier, cache_dir: Path, *, reanalyze: bool = False, on_progress: Callable[[str], None] | None = None) -> LayoutProfile
layout.model.OpenAIClassifier(base_url: str, model: str, api_key: str)
theme.service.plan_theme(book: Book, inventory: Inventory, profile: LayoutProfile, css: bytes | None = None) -> ThemePlan
verify.preservation.verify_output(book: Book, output: Path, plan: ThemePlan) -> dict[str, object]
verify.preservation.check_book(book: Book) -> dict[str, object]
```

`Classifier.classify(samples: Sequence[LayoutNode]) -> ClassificationBatch` returns exact requested IDs, validated roles/levels, token usage. It is the only injected model boundary for offline harness tests. No mocked production fallback. All data classes are frozen, but contained mappings are treated as read-only by consumers. Book.entries holds bounded decompressed member bytes; Book.infos retains original ZipInfo. No subsystem mutates Book.

## Archive and preservation invariants

Read ZIP without extraction. Fail unsafe/ambiguous names, duplicates including path aliases, encrypted ZIP entries, symlinks/special entries, CRC failures, compression errors, more than 10,000 members, any member over 128 MiB or aggregate over 512 MiB (check declared and actual bounded bytes). Reject external XML entity processing and network access. XML must be well-formed; no silent HTML recovery. Detect DRM/encrypted content via encryption.xml; font obfuscation alone is not DRM and original font bytes/metadata remain unchanged. Signed archives must fail rather than publish invalid signatures.

Require supported OPF version, manifest and spine references, unique manifest IDs/resolved resource paths, safe container/OPF paths and namespace-correct package resources. Follow declared media types rather than filename suffixes. Preserve book identifiers, metadata, original manifest entries, spine, NCX/NAV, links, IDs and untouched resources. XML serialization may change formatting/prefix spelling but not expanded names, attributes, element/text/tail topology, comments or processing instructions outside explicitly admitted edits. DTD/entity behavior must not silently drop text.

Source local references are resolved as URI paths with percent decoding and safe relative normalization; external links remain untouched. Check all relevant XHTML src/href, SVG href/xlink:href, manifest items and NCX targets, including fragments (id and legacy anchor name). Relative links cannot escape the archive. Existing broken local references fail with sanitized resource-only diagnostics, not arbitrary repair. Resolve package-declared covers/title pages, NAV/NCX and fixed-layout spine items as protected. Protect nav, pre/code, SVG, MathML, scripts/styles/forms, rt/rp/rtc subtrees. No model calls for fully protected documents. Natural inheritance from styled ancestors is not promised to be visually isolated.

Writer keeps all original members; untouched decompressed bytes exactly match. `mimetype` is first, uncompressed, exact application/epub+zip. ZIP metadata retained where public zipfile APIs permit; do not copy private stdlib internals to preserve incidental flags. Whole-archive binary identity is not promised. Only approved document bytes, OPF and new shuyi theme assets can differ.

## Role inventory and analysis

Roles: body, heading, chapter-number, subtitle, caption, quote, quote-text, quote-attribution, chapter-summary, table-text, list-text, footnote, endnote, noteref; unknown is null. Only heading has level 1..6. Explicit native semantics are evidence for the model, not a hidden second classifier. Inventory includes text-bearing h1-h6/p/li/blockquote/td/th/dt/dd/figcaption and containers with direct visible text. Do not duplicate every structural ancestor or classify whitespace/image-only blocks. Protected descendants must not become directly themed through parent assignment. Keep source paths and exact node source digest.

Evidence includes full candidate markup/text, bounded adjacent context (up to 1000 chars), relevant ancestor features and matched original CSS including inline styles. Do not infer semantics from class names globally. Group by tag/classes/epub type/ARIA/ancestor features and applicable CSS signatures. Source style differences such as nth-child or inline styles must split groups. Do not pass output CSS to the model. Namespace-aware read-only matching uses cssselect2. Reject unresolved imports, dynamic/unhandled matching CSS and source structures that cannot safely be interpreted; @page and @font-face are preserved, not used as node-semantic declarations. Static @media rules can be collected conservatively with condition labels; do not call this browser-computed style.

Group size <=6: classify all. Larger group: first/middle/last, then up to 3 held-out distinct candidates. Propagate only unanimously equal non-null role/level; otherwise classify remainder individually. Strict response schema `{observations:[{id,role,level}]}`, exact IDs once each, no unknown keys, no missing/extra IDs. Maximum 16 observations and 24,000 serialized request characters per request. Long own evidence is chunked completely (8000 chars each); classify chunks and accept a node only if all chunks agree; never silently truncate own content. If context itself cannot fit, fail a stable context-limit error.

Cache under XDG_CACHE_HOME/shuyi or ~/.cache/shuyi; cache identity source SHA256 + inventory/protocol version, NOT CSS or model identity. Record model provenance. Completed batches are atomic JSON checkpoints. Validate cached schema, IDs, source digests, roles and request bindings before reuse. Malformed or conflicting cache fails explicitly, not an unannounced paid restart. `--reanalyze` creates fresh working observations without destroying previously accepted profile until new profile succeeds. Failed model requests never become an accepted full profile. Concurrent analyses of same source use an exclusive advisory lock and explicit busy error. OpenAI SDK has finite timeouts, at most 2 retries, no provider fallback. Book text is untrusted evidence, not instructions. Report model usage, not invented monetary estimates.

## Theme compilation and notes

Built-in Chinese reading CSS is ported from wenyi's assets/chinese-reading.css, changing internal markers to `data-sy-*`. No fonts/network resources/scripts are bundled or fetched. Only admitted non-null role nodes receive markers and direct general styling. Unknown nodes retain original markup/styles; normal CSS inheritance can still affect them. Standard source prose spans (emphasis/bold/ruby base) remain intact.

Validate custom CSS with tinycss2: a restricted typography/color/spacing/border/pagination subset, static cssselect2 selectors, optional light/dark prefers-color-scheme only. Reject @import, @font-face, URL tokens, generated content, custom variables, animations/transitions, dynamic pseudo classes, pseudo-elements, executable resources and destructive display/position/layout properties. Internal note rules may additionally use bounded display/width/height/min-width. Custom styles must not directly theme unknown/protected nodes even with p/* selectors.

Preserve source CSS. Compile matching theme declarations into exact data-sy-node address rules with !important and specificity above original author stylesheet rules, capped at 128 guard IDs. Guard IDs must not exist anywhere in source. Inline !important declarations are demoted only for fully overridden property footprints; shorthand overlap without full safe coverage fails explicitly. No silent all:unset resets. Source cascade layers/nesting/animations or unresolved source cascade conditions fail safely when relevant. Record exact before/after attribute edits in the plan, including generated markers and inline priority changes. Theme asset path and OPF IDs are collision-checked; reject already-shuyi-styled inputs instead of accumulating layers. Add EPUB3 modified metadata only if required by standard, with explicit reversible plan entry; do not change book identity/version.

Note recognition is deterministic and model-independent. Explicit epub:type/ARIA noteref/backlink and footnote/endnote semantics with valid links are authoritative. Untyped labels qualify only when short numeric/symbol reference and leading return marker have safe reciprocal links; numeric pairs additionally need actual EPUB/ARIA or exact package/nav note context. Do not infer from class/file names alone or convert arbitrary numbered links. Change visible labels of confirmed reference/backlink anchors to real 注, including nested sup label text, preserving anchor descendants/attributes/IDs/hrefs and all tails outside the owned label. Add data-sy-note-kind markers; add compatible epub:type/ARIA semantics without overriding conflicting explicit semantics. Include exact text/attribute edits in plan. Built-in CSS renders the brown circle; custom CSS replaces general appearance but still honors the confirmed fixed note-label policy.

## Independent verification and publication

ThemePlan includes complete changed member bytes, original source digest, attribute/text edits, generated asset and OPF item identity, counts/warnings. Verifier reopens output with safe reader, checks exact member set and expected changed bytes, independently validates plan edits are restricted to permitted presentation attributes, fully covered inline-priority demotions, confirmed note label ownership and additive OPF theme entries, then reverses allowed edits and compares canonical original XML. Untouched resources compare by exact bytes, including original CSS/NAV/NCX/images/fonts. No blanket exemption for data attributes, no trusting output self-reports. Ensure prose/text-tail equality except admitted note-label edits. Validate generated CSS selectors/declarations against admitted role nodes and source cascade bounds independently rather than treating arbitrary plan bytes as trusted authorization. Use public shared low-level CSS primitives if necessary, not writer implementation imports.

Publish only after verification. Destination non-overwrite must be race-safe. Temporary files cleaned on failure. Report output SHA256, source SHA256, styled role/node counts, confirmed note-marker count, protected resources, unknown count, model usage and warnings. No claim of identical rendering across readers or of reader-tested behavior absent actual evidence.

## Harness and acceptance

Repository-owned `tests/fixtures.py` builds small EPUB2/3 archives and provides a deterministic Classifier test boundary; no provider requests in default suite. Tests exercise real CLI/application entry points and reopen output archives. Use unittest and temporary directories; no standalone throwaway validation drivers. Live acceptance is a separately selected unittest module using SHUYI_TEST_EPUB and real configured credentials. It invokes the installed CLI in subprocess, asserts note/text/resource preservation and cached second-run behavior, and writes output/evidence to SHUYI_TEST_OUTPUT_DIR. The copyrighted user book is never committed/copied into fixtures. Environment-gated live tests must clearly skip when input/config unavailable; a skip is not successful live acceptance.

Quality harness: `uv run python scripts/check_architecture.py`, `uv run ruff check .`, `uv run ruff format --check .`, `uv run python -m unittest discover -s tests`, `uv build`. Make targets expose check and explicitly opt-in acceptance. CI runs locked dependency installation and offline checks on Python 3.12 and 3.13. Architecture gate checks import directions/cycles, no sibling imports, <=500 lines/file, <=100 lines/function, <=300 lines/class, no production cross-module private imports. No test source-text pinning or wiring-only assertions. Required behavioral cases: EPUB2/3 end-to-end; native and p-only headings; unknown/protected nodes; nth-child/inline grouping; cache hits/no extra model calls; interruption/resume and refresh failure; malformed model responses/cache; safe and ambiguous note links; inline important/shorthand cascade; dangerous custom CSS; unsafe/oversize/encrypted archive; broken references; preserved binary resources; non-overwrite/failure cleanup; optional EPUBCheck missing/failure. Real-reader/browser inspection is supplementary visual evidence, never a substitute for archive/content proof.

Private acceptance inputs, book-specific observations and local model selections stay outside version control. Select inputs and configuration through the environment variables documented in HARNESS.md; never publish private paths, titles, excerpts or credentials.

## Resolved implementation details

- `epub.dom.node_digest(node)` hashes canonical XML bytes including comments but excluding the node's own tail; this public helper is used by inventory, theme and verifier. `serialize_xml` preserves document doctype and document-level siblings where present. Fail unsupported entities instead of dropping them.
- Inventory digest is SHA256 of UTF-8 canonical JSON (`sort_keys=True`, compact separators, ensure_ascii=False) of `{version: "shuyi-layout-v1", source_sha256, nodes: [dataclasses.asdict(node), ...]}`. Tuple paths serialize as arrays. Cache remains valid across model configuration changes; report the accepted profile's original provenance. Explicit --reanalyze is required to select new analysis.
- Validate exact requested observation IDs and roles at both analyzer and OpenAI transport boundaries. Null role and non-heading roles require null level; heading requires a strict non-bool integer 1..6. Usage values are nonnegative strict integers.
- Chunk evidence only when full request would exceed limits: stable IDs `NODE:cINDEX`, max 8000 characters of serialized own evidence per chunk, context/ancestor/CSS remain bounded and repeated; cache completed chunk IDs bound to SHA256 of exact chunk evidence. A node is accepted only after all chunks succeed and agree on a non-null assignment; disagreement yields null, partial completion remains resumable.
- Configuration precedence: explicit TOML values > OPENAI_BASE_URL/OPENAI_MODEL defaults > built-in endpoint/key-variable defaults. An explicit config file must exist; absent default config is allowed. Empty/missing selected credential fails model_config_missing at actual uncached model work. Fully cached analysis may complete without credentials.
- Refuse any existing destination using lstat, including broken symlinks. Compare resolved input/output paths before work. Publish a verified same-directory temp file using os.link(temp, destination), which atomically refuses existing destinations, then unlink the temp and fsync the parent where supported. Unsupported safe publication fails rather than falling back to an overwriting rename.
- Live acceptance command and environment are defined in HARNESS.md. SHUYI_LIVE_ACCEPTANCE=1 is required; SHUYI_TEST_EPUB and SHUYI_TEST_OUTPUT_DIR select local private input and evidence/output directory.
- `epub.notes.find_note_markers(book: Book) -> tuple[NoteMarker, ...]` is the shared pure source-relation recognizer; renderer and independent verifier both consume it. It does not mutate markup or choose theme appearance.
- `epub.styles.style_evidence(book, resource, root) -> dict[ElementPath, str]` provides deterministic matched original CSS/inline evidence and ancestor signatures for each element. `epub.styles.specificity_guard(book, resource, root) -> int` returns an ID guard count strictly above source author ID specificity (maximum 128). CSS safety/matching primitives live here and are shared with verification; they do not apply DOM edits. The theme executor owns this file; archive executor owns other epub files.
- Reserved attributes are `data-sy-node`, `data-sy-role`, `data-sy-level`, `data-sy-content`, `data-sy-note-kind`, `data-sy-note-id`. Reserved never-match selector ID is `shuyi-never`; source collision fails. Generated asset is OPF-relative `shuyi/reading.css`, manifest ID `shuyi-reading`; collisions fail. General CSS selectors address data-sy-node and repeat `:not(#shuyi-never)` guard count times. Confirmed note-only anchors receive globally unique data-sy-note-id and note-kind, without needing a model role or data-sy-node; nested label CSS is scoped to that unique note address. Do not add generated IDs to content.
- Preserve original EPUB/ARIA note semantics unless compatible new metadata is added; no namespace cleanup. Renderer and verifier account for exact attribute/text edits. Unrecognized notes retain labels and link graph.
- `epub.styles.validate_generated_css(book, plan, output_book) -> None` and `validate_inline_demotion(before, after, properties) -> None` are public shared verification primitives. They validate safety/scope/cascade, not arbitrary writer output equality.
- EPUB3 publication updates only dcterms:modified to UTC seconds, or adds it if absent. This is an explicit reversible metadata exception; all other original metadata remains unchanged. EPUB2 metadata is unchanged apart from adding the theme manifest item.
- Live acceptance may read an explicitly selected local model configuration. Pass credentials only through the child process environment or a private user configuration file with mode 0600. Never store real credentials or personal model selections in version-controlled project files, reports or logs.
- Confirmed note labels containing a comment/PI with non-whitespace tail cannot be represented by ElementPath/TextEdit and fail theme_note_label_unsupported. Ordinary comments/PIs and their whitespace remain preserved; no partial label conversion.
- Theme value validation uses a finite set of reading-style keyword grammars, CSS3 colors, font-family syntax and simple numeric dimensions. Arithmetic functions are unsupported. Invalid/empty declarations cannot authorize inline priority demotion. Source @namespace is explicitly rejected; it must not be silently discarded or replaced with a guessed namespace. Font-variant, border-radius and legacy page-break aliases participate in coverage footprints.
- Completed accepted analysis removes its working checkpoint; an interrupted --reanalyze preserves the prior accepted profile and resumes the pending working batches when --reanalyze is retried. Normal export continues to use the prior accepted profile while refresh is incomplete.
